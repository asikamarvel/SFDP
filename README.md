# Society for Disease Prevention (SFDP)

**Website:** [s-fdp.org](https://s-fdp.org)

SFDP is a nonprofit organization empowering communities in Pennsylvania and Africa with life-saving healthcare, education, and sustainable solutions. We work to prevent public health crises through technology, education, and community engagement.

## About This Repository

This repository contains the source code for the SFDP website — a static HTML/CSS/JavaScript site featuring:

- **Homepage** – mission overview, featured programs, and newsletter sign-up
- **Blog** – health education articles (60+ posts in Markdown format)
- **Projects** – current programs and initiatives
- **Editorial** – opinion and research pieces
- **About / Mission / Contact** – organizational information
- **Donate / Join Us** – ways to support the organization
